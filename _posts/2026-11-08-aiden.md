Características principales
Arquitectura modular orientada a investigación OSINT.
Integración de Maigret como motor de descubrimiento de cuentas y usernames.
Interfaz web para ejecutar y visualizar investigaciones.
Generación de grafos y representación de relaciones entre resultados.
Extracción y organización de información pública obtenida durante las búsquedas.
Generación de informes en diferentes formatos.
Ejecución aislada mediante entorno virtual Python sobre Debian.
Automatización del entorno de investigación mediante Termux.
Enfoque técnico

AIDEN parte de una premisa sencilla: aprovechar herramientas especializadas existentes y construir una capa propia de integración, análisis y visualización sobre ellas.

La arquitectura está planteada de forma modular para mantener separados:

Motor de descubrimiento.
Extracción de información.
Correlación de resultados.
Representación gráfica.
Gestión de evidencias.
Generación de informes.
Interfaz de usuario.

Maigret actúa como uno de los componentes externos del sistema, mientras que la arquitectura y las capas desarrolladas alrededor de él forman parte del proyecto AIDEN.

Arquitectura

El proyecto busca evolucionar progresivamente desde una herramienta de búsqueda de usernames hacia una plataforma capaz de combinar diferentes fuentes y métodos de investigación.

La separación por módulos permite incorporar nuevos motores y fuentes sin depender de una única herramienta.

La prioridad inicial es mantener una arquitectura clara, reproducible y extensible antes de aumentar la complejidad funcional del sistema.

Entorno de ejecución

El entorno actual utiliza:

Debian sobre Termux.
Python y entornos virtuales.
Flask para la interfaz web.
Maigret como motor OSINT.
NetworkX y PyVis para representación y análisis de grafos.
BeautifulSoup para procesamiento de información web.
ReportLab para generación de documentos.
XMind para representación estructurada de investigaciones.

El entorno se inicia mediante un comando único, automatizando la preparación del entorno virtual y el lanzamiento de la interfaz web.

Estado del proyecto

Primera versión en desarrollo.

La base funcional ya permite ejecutar investigaciones mediante Maigret y visualizar los resultados a través de una interfaz web.

A partir de esta base, el proyecto evolucionará progresivamente hacia una arquitectura más modular, con mayor capacidad de correlación, análisis, visualización y generación de informes.

Es un proyecto personal orientado a explorar la aplicación práctica de Python, Linux, automatización, análisis de información y desarrollo de herramientas OSINT.
